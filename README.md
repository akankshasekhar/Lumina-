# Lumina Digital Library

Lumina is a responsive, AI-assisted educational web application prototype built to provide students with a distraction-free digital reading environment. This project was developed by Akanksha Sekhar as part of the Semester 3 End Semester Exam (ESE) for the Artificial Intelligence and Data Science program at Marwadi University.

## Core Features
* **Curated Catalog:** A responsive grid displaying featured books with title, author, and genre tags.
* **Bookshelf Drawer:** An interactive slide-over interface tracking both the "Currently Reading" queue and completed "Reading History" using browser local storage state persistence.
* **Pomodoro Focus Timer:** An integrated 25-minute countdown modal with strict interval management to support deep work and uninterrupted study sessions.
* **Dynamic UI:** A rotating "Quote of the Day" hero section and real-time navigation badge updates.

## Tech Stack
* React
* TypeScript
* Tailwind CSS
* Vite

## Deployment Instructions (Netlify)
This application is optimized for continuous deployment via Netlify. 
1. Connect this GitHub repository to Netlify.
2. Set the Build Command to: `npm run build`
3. Set the Publish Directory to: `dist`
4. Deploy the site.
